## 摘要
视觉提示（Visual prompting）已成为一种强大的方法，可以在不更新模型参数的情况下将预训练模型适配到新领域。然而，现有的提示方法通常为每个领域优化单个提示，并将其统一应用于所有输入，这限制了它们在域内和域间变异性下的泛化能力，而这在医学领域尤为关键。为此，我们提出了 APEX，一个自适应提示提取（Adaptive Prompt EXtraction）框架，该框架从可学习的提示记忆库中检索特定于输入的提示。该记忆库存储了多样化且具有领域辨别力的提示表示，并通过从傅里叶频谱中提取的领域特征进行查询。为了学习鲁棒且具有辨别力的领域特征，我们引入了一种新颖的低频特征对比（LFC）学习框架，该框架将来自同一领域的表示聚类，同时分离来自不同领域的表示。在两个医学分割任务上的广泛实验表明，APEX 显著提高了在已知和未知领域上的泛化能力。此外，它与任何现有的骨干网络互补，并持续提升性能，证实了其作为医学领域即插即用提示解决方案的有效性。代码可在 https://github.com/cetinkayaevren/apex/ 获取。

## Abstract
Visual prompting has emerged as a powerful method for adapting pre-trained models to new domains without updating model parameters. However, existing prompting methods typically optimize a single prompt per domain and apply it uniformly to all inputs, limiting their ability to generalize under intra and inter-domain variability, which is especially critical in the medical field. To address this, we propose APEX, an Adaptive Prompt EXtraction framework that retrieves input-specific prompts from a learnable prompt memory. The memory stores diverse, domain-discriminative prompt representations and is queried via domain features extracted from the Fourier spectrum. To learn robust and discriminative domain features, we introduce a novel Low-Frequency Feature Contrastive (LFC) learning framework that clusters representations from the same domain while separating those from different domains. Extensive experiments on two medical segmentation tasks demonstrate that APEX significantly improves generalization across both seen and unseen domains. Furthermore, it complements any existing backbones and consistently enhances performance, confirming its effectiveness as a plug-and-play prompting solution in medical fields. The code is available at https://github.com/cetinkayaevren/apex/

### 1. 核心问题与研究动机
医学图像分割面临严重的**域偏移（Domain Shift）**问题，不同设备、机构或采集设置会导致模型性能大幅下降。
*   **现有方法的局限：** 传统的微调（Fine-tuning）容易导致“灾难性遗忘”；现有的视觉提示（Visual Prompting, VP）方法通常为每个域优化一个固定提示，并统一应用于该域所有图像。
*   **核心挑战：** 这种“一刀切”的方法忽略了**域内变异性**（同一设备下不同患者、病理特征的差异）和**域间变异性**（不同设备间的显著差异），导致模型在未知域（Unseen Domains）的泛化能力受限。

### 2. 核心方法论：APEX 框架
论文提出了 **APEX (Adaptive Prompt EXtraction)** 框架，旨在实现输入自适应的提示生成。
*   **核心思想：** 不再使用固定提示，而是根据输入图像的特征，从一个“提示记忆库”中动态检索并组合最相关的提示信息。
*   **关键技术细节：**
    1.  **频域处理：** 利用傅里叶变换（FFT）提取图像的低频振幅分量。研究认为医学图像的域差异主要集中在低频（对比度、亮度等），而高频和相位保留了解剖结构。
    2.  **域特征编码器 ($E_D$)：** 从低频分量中提取 $K$ 维域特征向量。
    3.  **提示记忆库 (Prompt Memory, $B$)：** 存储 $J$ 个可学习的提示向量。通过计算输入特征与记忆库向量的余弦相似度，生成“寻址向量”（Addressing Vector），以加权求和的方式提取最终提示特征。
    4.  **提示解码器 ($D_P$)：** 将提取的特征解码为空间维度的视觉提示，并作用于原图的低频分量。
    5.  **低频特征对比学习 (LFC)：** 引入对比损失函数，强制同一域的低频特征相互靠近，不同域的相互远离，从而增强特征的辨别力。

### 7. 亮点与优点
*   **动态性：** 突破了传统 VP 方法“一域一提示”的限制，实现了“一图一提示”。

*   **泛化能力：** 证明了通过记忆库检索机制，模型可以处理训练时未见过的分布，具有极强的临床实用价值。

### 8. 不足与局限
*   **解剖结构偏移：** 目前的方法主要针对同一解剖结构在不同设备间的偏移。如果跨越不同的解剖部位（如从心脏到肝脏），该方法的有效性尚未验证。

*   **高频信息忽略：** 提示仅作用于低频分量，虽然保护了结构，但也可能错失了通过调整高频细节进一步优化分割精度的机会。
