## 摘要
数字组织病理学分割中的一个关键挑战是染色间和染色内的差异，因为这会降低模型性能。为每种染色进行标注既昂贵又耗时，因此开发了利用 CycleGAN 进行染色迁移的方法，以便使用单一染色的标签来训练多染色分割模型。然而，由于某些染色对之间存在一对多的特性，CycleGAN 在转换过程中往往会引入噪声，这与其循环一致性损失相冲突。为解决这一问题，我们提出了领域偏移感知 CycleGAN（DSA-CycleGAN），旨在减少此类噪声的出现。此外，我们评估了机器学习领域旨在解决类似问题的几项进展，并在多染色肾小球分割的背景下将其有效性与 DSA-CycleGAN 进行了比较。实验表明，DSA-CycleGAN 不仅提高了肾小球分割的性能，而且在减少噪声方面也优于其他方法。这在生物学特征差异显著的染色之间进行转换时尤为明显。代码已在 https://github.com/zeeshannisar/DSA-CycleGAN 公开。

## Abstract
A key challenge in segmentation in digital histopathology is inter- and intra-stain variations as it reduces model performance. Labelling each stain is expensive and time-consuming so methods using stain transfer via CycleGAN, have been developed for training multi-stain segmentation models using labels from a single stain. Nevertheless, CycleGAN tends to introduce noise during translation because of the one-to-many nature of some stain pairs, which conflicts with its cycle consistency loss. To address this, we propose the Domain Shift Aware CycleGAN, which reduces the presence of such noise. Furthermore, we evaluate several advances from the field of machine learning aimed at resolving similar problems and compare their effectiveness against DSA-CycleGAN in the context of multi-stain glomeruli segmentation. Experiments demonstrate that DSA-CycleGAN not only improves segmentation performance in glomeruli segmentation but also outperforms other methods in reducing noise. This is particularly evident when translating between biologically distinct stains. The code is publicly available at https://github.com/zeeshannisar/DSA-CycleGAN.

### 1. 核心问题与整体含义（研究动机和背景）
在数字病理学中，不同染色（如 PAS、H&E、IHC 等）会突出不同的生物结构。由于标注每种染色的图像成本极高，研究者通常使用 **CycleGAN** 进行染色迁移（Stain Transfer），即利用一种已标注的染色（源域）来训练模型，再将其应用于未标注的其他染色（目标域）。
然而，CycleGAN 存在一个固有缺陷：当从信息贫乏的域（如只标记特定蛋白的 IHC 染色）转换到信息丰富的域（如显示全面组织结构的 PAS 染色）时，由于“一对多”的映射关系，生成器为了满足循环一致性损失，往往会在图像中嵌入不可见的**隐写噪声**（Steganographic Noise）来存储丢失的信息。这种噪声会导致严重的**领域偏移（Domain Shift）**，显著降低下游分割模型的准确率。

### 2. 方法论：核心思想与关键技术
DSA-CycleGAN 的核心思想是**将领域偏移度量（Domain Shift Metric, DSM）直接集成到 CycleGAN 的损失函数中**，作为一种自引导策略来约束生成器。

*   **领域偏移度量 (DSM)**：利用预训练的源域分割模型提取特征。通过计算源域真实图像与转换后图像在特征层激活值的均值分布差异（使用 **Wasserstein 距离**），量化两者之间的领域偏移。
*   **损失函数设计 ($L_{dsl}$)**：
    *   **$L_{dsl\_fake}$**：约束目标域到源域的转换过程（T → S），确保生成的图像在特征分布上接近真实源域。
    *   **$L_{dsl\_cyc}$**：约束循环重建过程（S → T → S），减少重建过程中的信息隐藏。
    *   **$L_{dsl\_id}$**：约束恒等映射（Identity Mapping），增强模型对源域特征的保持能力。
*   **总损失**：$L_{CycleGAN} = L_{adv} + w_{cyc}L_{cyc} + w_{id}L_{id} + w_{dsl}L_{dsl}$。通过最小化 $L_{dsl}$，强制生成器学习更准确的生物特征转换，而非依赖噪声。

### 6. 主要结论与发现
*   **性能提升**：DSA-CycleGAN 在所有染色任务中均表现优异，尤其在生物学差异巨大的 IHC 染色（CD68, CD34）上，F1 分数显著高于原始 CycleGAN 和其他改进方法。
*   **噪声抑制**：相比于增加通道或加高斯噪声的方法，DSA-CycleGAN 能更有效地抑制导致领域偏移的噪声。
*   **适用场景**：
    *   对于生物学相似的染色（HC ↔ HC），加入高斯噪声的方法效果较好。
    *   对于生物学差异大的染色（HC ↔ IHC），DSA-CycleGAN 具有明显优势。

### 7. 优点
*   **无需额外标注**：在 CycleGAN 训练阶段不需要目标域的 Ground Truth，完全基于无监督的领域适配。
*   **端到端约束**：通过 DSM 损失直接作用于 T → S 的转换路径，这比以往只约束循环路径的方法更直接、更有效。
*   **通用性**：该损失项可以轻松集成到其他生成模型（如 StarGAN 或 Encoder-Decoder 架构）中。

### 8. 不足与局限
*   **依赖预训练模型**：DSM 的计算依赖于一个在源域上表现良好的预训练分割模型，如果源域模型本身特征提取能力不足，可能会影响约束效果。
*   **计算开销**：在训练过程中需要频繁调用预训练模型提取特征并计算 Wasserstein 距离，这会增加训练时的内存占用和计算耗时。
*   **超参数敏感性**：虽然文中给出了推荐值，但 $w_{dsl}$ 等权重在不同器官或更极端的染色对之间可能需要重新调优。
