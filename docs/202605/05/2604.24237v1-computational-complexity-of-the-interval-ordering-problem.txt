Abstract 

We study an interval ordering problem introduced by Dürr et al. [Discrete Appl. Math. 2012] which is motivated by applications in bioinformatics. The task is to order a given set of n intervals with the goal of minimizing a certain objective which is defined via a given cost function f which assigns a cost to the exposed part of each interval (that is, the pieces not covered by previous intervals). We develop a dynamic programming approach which solves the problem with O(2 npoly (n)) oracle calls to f and arithmetic operations. Moreover, our approach yields polynomial-time algorithms for all cost functions f such that f − f (0) is subadditive or superadditive. This answers an open question for the function f (x) = 2 x. We contrast these results by proving a running time lower bound of 2n−1 for any algorithm that solves the problem for every function f (with oracle access only) and further proving NP-hardness for very restricted classes of functions. Thus, we significantly narrow the gap regarding the computational complexity of the problem.

## 1 Introduction 

We study the f -Interval Ordering problem introduced by Dürr et al. [ 4] where we are given a set I of n intervals Ij = [ aj , b j ) ⊂ R with aj < b j for j = 1 , . . . , n and the task is to find a total ordering of the intervals that minimizes the overall costs depending on the “exposed parts” of the intervals. For an ordering σ = ( σ(1) , . . . , σ (n) ) ∈ Sn (where Sn denotes the set of permutations of {1, . . . , n }), the exposed part of an interval Ij is Eσ,j := Ij \⋃ 

> i:σ−1(i)<σ −1(j)

Ii,that is, the subset of Ij which is not “covered” by intervals coming before Ij in σ (see Figure 1 for an illustration). Note that Eσ,j is a union of disjoint intervals. Its length |Eσ,j | is defined as the total sum of the lengths of its individual intervals (an interval [a, b ) has length |[a, b )| := b − a). Now, a given cost function f : [0 , ∞) → R assigns a cost to each interval depending on the length of its exposed part. Formally, the decision problem is defined as follows. 

▶ Problem 1. f -Interval Ordering .

This problem can be simplified to a certain bitstring reconstruction problem where the goal is to find a binary string such that for given index intervals, the corresponding substring equals an unknown string. Equality can only be tested via an oracle, which means that one has to try all possible substrings in the worst case. Besides this direct application, f -Interval Ordering is a natural interval scheduling problem which might find further applications and which we believe to be of independent interest on its own. Dürr et al. [ 4 ] showed that f -Interval Ordering is NP-hard for a rather artificial (discontinuous non-monotonic) cost function f , but solvable in polynomial time if the input intervals are agreeable , that is, there is an ordering induced by the left interval end points which is the same as an ordering induced by the right end points. They also prove polynomial-time solvability for laminar intervals (that is, for every two intervals Ii, I j , either Ii ∩ Ij = ∅

or one is contained in the other) if the function f − f (0) is superadditive (note that their NP-hardness result holds for laminar intervals). Most importantly, they posed the open question whether the problem is polynomial-time solvable for the cost function f (x) = 2 x,which constitutes the motivating use-case in biochemistry. 

Our Results. In this work, we answer this question positively showing that f -Interval Ordering can be solved in polynomial time for all functions f for which f − f (0) is superadditive. Our main contribution is a dynamic programming algorithm described in Section 3 that solves f -Interval Ordering for arbitrary cost functions in O(n3 · 2n) time (assuming f can be computed in constant time). The algorithm is based on the key idea to consider all possible exposed (and covered) parts instead of the intervals themselves. This view allows us to do a refined analysis of the structure of exposed parts in Section 4 to obtain polynomial-time algorithms for all cost functions f where f − f (0) is subadditive or superadditive. We also show that the case of pairwise intersecting intervals can be solved in O(n5) time for arbitrary cost functions. We complement our algorithmic results in Section 5 by showing a worst-case running time lower bound of 2n−1 for every algorithm solving f -Interval Ordering for arbitrary f with only oracle access to f . ## 2 Preliminaries 

For n ∈ N, we define [n] := {1, . . . , n }. A function f : [0 , ∞) → R is superadditive (subadditive )if f (x + y) ≥ f (x) + f (y) (f (x + y) ≤ f (x) + f (y)) for all x, y ∈ [0 , ∞).We consider intervals of the form I = [a, b ) ⊂ R with a < b ∈ R. We call a the start point and b the end point of I. The length |I| of I is defined as b − a. We say that two intervals Ii and Ij touch each other if they are disjoint and their union is an interval. ## 4 Polynomial-Time Solvable Cases 

In this section, we use the approach described in Section 3 to obtain polynomial-time algorithms for special cost functions answering the open question by Dürr et al. [ 4] regarding the function f (x) = 2 x. In particular, we give an O(n5)-time algorithm for every cost function f where f − f (0) is superadditive. 

## 4.1 Subadditive f − f (0) 

First, we have a look at cost functions f where f − f (0) is subadditive, that is, f (a) +

f (b) ≥ f (a + b) + f (0) holds for all a, b ∈ [0 , ∞) (for example, every subadditive function f

with f (0) ≤ 0). For such functions, we show the following. 

▶ Lemma 6. Let f be a cost function such that f − f (0) is subadditive. Then there is an optimal sequence where all exposed parts are intervals. 

Proof. Assume that (I1, . . . , I n) is an optimal sequence where Ij has an exposed part Ej

that is not an interval, that is, it has at least two interval components. This means that the covered area of {I1, . . . , I j−1} has an interval component that is a subinterval of Ij . Therefore, the intervals before Ij that cover this interval component are also subintervals of Ij (see Figure 3). Let those intervals be Ii1 , . . . , I ik and let their exposed parts be Ei1 , . . . , E ik . Now consider what happens if we change Ii1 , . . . , I ik to come after Ij . Then the exposed parts of Ii1 , . . . , I ik will be empty and the exposed part of Ij will increase by |Ei1 | + · · · + |Eik |.Subadditivity now yields

This rearrangement reduces the number of interval components of the exposed part of Ij while not increasing the number of interval components of any other exposed part. Now, any interval I ∈ I that starts before C cannot have E as its exposed part in any sequence. Hence, in O(n) time we can discard all intervals which cannot have an exposed part starting at a. For the remaining candidates, we analogously check the conditions for b′ and then discard all remaining intervals which cannot have an exposed part ending at b. That is, we can check if E is an exposed part in some sequence in O(n) time. ◀

This lets us formulate our first result. 

▶ Theorem 8. Any instance of f -Interval Ordering that has an optimal sequence where all exposed parts are intervals can be solved in O(n4) time. 

Proof. By Lemma 7, we can compute the set E′I of non-empty exposed parts that are intervals in O(n3) time and its size is bounded in O(n2). We simply use the set E′I instead of EI in Algorithm 1 to find an optimal sequence in O(n2 · |E ′I |) = O(n4) time. Note that, for each E ∈ E ′I , the running time is constant since E is an interval. ◀

## 4.2 Superadditive f − f (0) 

If f − f (0) is superadditive, then f (a + b) + f (0) ≥ f (a) + f (b) holds for all a, b ∈ [0 , ∞) (for example, every superadditive function with f (0) ≥ 0). This case is of special interest because such cost functions are somewhat natural for applications (like the function 2x in the original motivation). Again, we observe a special structure of optimal sequences for this case. 

▶ Lemma 10. Let f be a cost function such that f − f (0) is superadditive. Then there is an optimal sequence where no interval comes before any of its proper subintervals. 

Proof. Assume that there is an optimal sequence where an interval Ii comes after the interval Ij , but Ii is a proper subset of Ij . Let Ei = ∅ and Ej be the exposed parts of Ii

and Ij respectively. Consider what happens when we change the interval Ii to be right before the interval Ij . Then, only the exposed parts of Ii and Ij can change. The exposed part of Ii

will be Ej ∩ Ii and the exposed part of Ij will be Ej \ Ii (see Figure 4). By superadditivity, it holds: 

f (|Ei|) + f (|Ej |) = f (0) + f (|Ej ∩ Ii| + |Ej \ Ii|) ≥ f (|Ej ∩ Ii|) + f (|Ej \ Ii|).Therefore, the cost does not increase. We can repeat this step finitely many times until there are no more intervals before any of their proper subintervals. As we started with an optimal sequence and we did not increase the cost, this will be an optimal sequence as well. ◀

Next we show that the number of exposed parts to consider is polynomially bounded. 

▶ Lemma 11. Let E′I ⊆ E I be the set of all non-empty exposed parts appearing in sequences where no interval comes before any of its proper subintervals. Then |E ′I | ∈ O (n2) and we can compute E′I in O(n3) time. 

Proof. As regards the size of E′I , consider an arbitrary exposed part E ∈ E ′I of an interval I

and let s be the start point of the first interval component of E and let t be the end point of the last interval component. Note that there cannot be another different exposed part also starting at s and ending at t since all proper subintervals of [s, t ) in I must come before any interval with such exposed part. That is, each exposed part in E′I is uniquely defined by the start point of its first interval component and the end point of its last interval component. This yields |E ′I | ∈ O (n2).To compute E′I , we iterate over all intervals I = [ a, b ) ∈ I . We first compute the covered area C of all proper subintervals of I in I in O(n) time (assuming the intervals are sorted) and add the exposed part E := I \ C to E′I in O(n) time. Then, we iterate over each pair of 10 Computational Complexity of the Interval Ordering Problem 

intervals [a′, s ) ∈ I and [t, b ′) ∈ I with a′ < a ≤ s < t ≤ b < b ′ and remove them from E and add the result to E′I . As the exposed parts are uniquely defined by s and t, we can check for duplicates in constant time when storing exposed parts via pairs (s, t ) in an n × n matrix. Overall, this takes O(n3) time. ◀

So, again we obtain a polynomial-time algorithm. 

▶ Theorem 12. f -Interval Ordering can be solved in O(n5) time for every f where 

f − f (0) is superadditive. 

Proof. By Lemma 11, we can compute the set E′I in O(n3) time. Iterating over E′I in Algorithm 1, we obtain a solution in O(n3 · |E ′I |) = O(n5) time. ◀

## 4.3 Pairwise Intersecting Intervals 

So far, we developed polynomial-time algorithms for special cost functions. As a side result, we show that intervals that pairwise touch or intersect each other are also solvable in polynomial time for every function f . Note that in this case all covered areas are intervals. Using Algorithm 1, one can solve such instances in polynomial time. 

▶ Theorem 13. Any f -Interval Ordering instance where each covered area is a single interval can be solved in O(n5) time. 

Proof. As all covered areas are intervals, there are only O(n2) many. Hence, there are 

O(n2) exposed parts for every interval and we can find them by just going through all covered intervals. Additionally, all exposed parts have at most two interval components. Thus, |E I | ∈ O (n3) and Algorithm 1 solves the instance in O(n2 · |E I |) = O(n5) time (since each exposed part takes constant time). ◀

We remark that the running time can be improved to O(n3) with a more specialized dynamic programming approach than our general Algorithm 1.

## 6 Parameterized Complexity 

In this section, we introduce a more fine-grained analysis of the computational complexity of f -Interval Ordering . To this end, we identify certain parameters which render the problem tractable when their values are small (constants). As the exponential part of the S. Pawlowski and V. Froese 13 

running time of our general algorithm depends on the number |E I | of possible exposed parts, we aim for parameters which bound this number. Our first parameter is the maximum number of interval components of any exposed part in EI , which we call αI . Note that we have already seen a polynomial-time algorithm for the case that αI = 1 in Theorem 8. We generalize this result to any constant value of αI (in terms of parameterized complexity, the problem is in XP for parameter αI ). 

▶ Theorem 18. The size of EI is bounded in O(n2αI

). Thus, f -Interval Ordering is polynomial-time solvable whenever αI is constant. 

Proof. Each interval component of an exposed part has at most n possible start and end points. Thus, each exposed part has at most n2 possible interval components. So, for each non-empty exposed part, we have at most αI choices, each being one of the at most n2

interval components. This yields O(n2αI

) different exposed parts. To compute EI , we iterate over all intervals I in I and compute all covered intervals that are contained in I. As any exposed part has at most αI interval components, we can partition the covered intervals into at most αI − 1 sets of pairwise intersecting or touching covered intervals. Then we just iterate over all combinations of covered intervals to find all exposed parts. To prevent duplicates, we keep the exposed parts in a balanced search tree. Thus, we can compute the set EI in O(n2αI +c) time for some constant c. ◀

It is unclear whether the exponential part of the running time can be solely confined to αI ,that is, whether a running time of g(αI ) · nO(1) is possible (this is called fixed-parameter tractability in parameterized complexity [ 2]). However, for the parameter sI defined as the maximum number of proper subintervals any interval I ∈ I has in I, fixed-parameter tractability can be shown (note that agreeable intervals have sI = 0 ). 

▶ Theorem 19. The size of EI is bounded in O(n2 · 2sI

). Thus, f -Interval Ordering is fixed-parameter tractable with respect to sI .

Proof. Clearly, there are O(n2) possible pairs of first start and last end points of the interval components of any exposed part. The interval spanned by the first start and last end point of any exposed part has at most sI subintervals in I. Hence, there are at most 2sI different exposed parts for each combination of first start and last end point. So, overall there are 

O(n2 · 2sI

) possible exposed parts. It is easy to see that we can compute the set EI in 

O(nc · 2sI ) time for some constant c, as we just have to try all combinations and, like in Lemma 4, keep all exposed parts we find in a balanced search tree to detect duplicates in polynomial time. ◀

## 7 Conclusion 

We took a large step towards settling the computational complexity of the interval ordering problem. As regards the cost function, we showed broad families of functions to be polynomial-time solvable while we showed NP-hardness already for some very restricted functions. It might be interesting to further close the gap between the tractable and intractable cases by identifying the specific properties that render a function tractable. For example, the complexity for subadditive and superadditive functions is open. Regarding running times, on one side, there is clearly the challenge to improve the polynomial running times. This may allow experiments on real-world datasets in order to evaluate whether integrating an f -Interval Ordering solver into actual protein backbone reconstruction algorithms is worth the computation overhead. On the other side, proving 14 Computational Complexity of the Interval Ordering Problem 

conditional running time lower bounds for the polynomial-time solvable cases would also be interesting. Moreover, we initiated the study of the parameterized complexity of the problem. It could be fruitful to identify parameters which render instances tractable in practice. For example, it is open whether the problem is fixed-parameter tractable for the maximum number αI of interval components of any exposed part.
